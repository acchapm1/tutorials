# Tutorials

A growing collection of tutorials on CLI tools, dev environments, terminal
multiplexers, automation, macOS productivity, and HPC workflows.

**Live site:** https://acchapm1.github.io/tutorials/

Every topic gets two writeups: a **beginner guide** and a **deep-dive
reference**. New tutorials are generated by an automated pipeline — see
[NewTutorial/how-i-create-new-tutorials.md](NewTutorial/how-i-create-new-tutorials.md)
for the workflow.

## What's inside

The tutorials cluster into a handful of themes:

- **Terminal & multiplexers** — `Tmux-Claude-Code`, `Sesh`, `Honeymux`,
  `OpenMux`, `Dtach`, `Television`
- **Shell & dotfiles** — `Chezmoi`, `Dotfiles`, `Pet`, `GitHub-CLI`, `Just`
- **macOS productivity** — `Bunch`, `Hammerspoon`, `Karabiner-Elements`,
  `Moom`, `Yabai`, `Sketchybar`, `macOS-App-Layout-Management`
- **Python tooling** — `Uv`, `Pixi`, `Parsl`
- **HPC & schedulers** — `HyperQueue`, `Apache-NiFi-HPC-Sysadmin`,
  `IsaacLab-MetaGrasp-Apptainer-HPC`
- **Containers & infra** — `Docker-Test-Container`, `Kubernetes`,
  `Apache-NiFi`
- **Networking & access** — `SSH`, `Mosh`
- **Embedded** — `MicroPython`, `TTGO-Display`
- **Git workflows** — `Git-Worktrees-Worktrunk`, `Worktrunk`
- **Claude Code** — `Claude-Code-VSCode-Go`, `agent-skills`,
  `claude-agents-library`
- **System fundamentals** — `Linux-Permissions`, `Maestri`

## Reading the tutorials

The easiest way is the [hosted site](https://acchapm1.github.io/tutorials/) —
sidebar navigation, search, dark mode. You can also just browse the folders
on GitHub; every `.md` file renders fine in the GitHub UI.

## Building the site locally

The hosted site is generated with [Docusaurus](https://docusaurus.io/). The
`website/` directory holds the build config; the markdown lives at the repo
root and is sourced from there.

```bash
cd website
npm install        # first time only
npm start          # dev server with hot reload
npm run build      # production build into website/build/
```

## Deploying

Push to `main`. A GitHub Actions workflow
([.github/workflows/deploy.yml](.github/workflows/deploy.yml)) builds and
publishes to GitHub Pages automatically.

## Repository layout

```
tutorials/
├── NewTutorial/                       ← workflow docs + drop zone
│   ├── how-i-create-new-tutorials.md  ← published: the workflow
│   └── drop-zone/                     ← new topic prompts (gitignored)
│       └── finished/                  ← archive of past prompts
├── {Topic}/                           ← one folder per topic, x38
│   ├── {topic}-beginner-guide.md
│   └── {topic}-deep-dive.md
├── website/                           ← Docusaurus site
└── .github/workflows/deploy.yml       ← auto-deploy on push to main
```
